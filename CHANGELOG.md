# Changelog

All notable changes to vNotes are documented in this file.

## [1.0.0] - 2026-08-24

### Added

- GitHub OAuth authentication and repository-backed note storage.
- Markdown, rich-text, split-view, and read-only code viewing modes.
- Repository file tree with create, delete, move, and inline rename support.
- Command palette, repository-wide search, and automatic table of contents.
- Mermaid diagram rendering and drag-and-drop image uploads.
- Responsive desktop and mobile layouts.

### Fixed

- Image rendering and path handling across editor modes.
- List markers in rich-text and Markdown previews.
- Open-note paths after moving files.
- Supported code-file discovery across repositories.
